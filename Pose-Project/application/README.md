# Pose Classifier

แอปจำแนกท่าทางจากกล้องหรือรูปภาพ ใช้โมเดล Pose จาก Teachable Machine

## ติดตั้ง

รันครั้งเดียวที่โฟลเดอร์บนสุดของ repo ใช้ได้ทั้ง macOS, Linux และ Windows (Git Bash หรือ WSL)

```bash
bash install.sh
```

บน Windows ที่ไม่มี Git Bash ให้ดับเบิลคลิก `install.bat` แทน แอปบนเว็บใช้แค่ Python ส่วนไลบรารีที่ติดตั้งเพิ่มใช้กับไฟล์ `run_model.py`

## เปิดแอปบนเว็บ

```bash
bash run.sh pose
```

หรือดับเบิลคลิก `run.command` บน macOS หรือ `run.bat` บน Windows แล้วเปิด <http://localhost:8003/>

ต้องเปิดผ่าน `localhost` เพราะเบราว์เซอร์ไม่อนุญาตให้ใช้กล้องและโหลดโมเดลเมื่อเปิดไฟล์ HTML ตรง ๆ
และต้องต่ออินเทอร์เน็ต เพราะแอปโหลดไลบรารี TensorFlow.js กับฟอนต์จาก CDN

## รันด้วย Python

```bash
bash run.sh pose python                                    # เปิดกล้อง
bash run.sh pose python --source Pose-Project/Data-Test    # ทำนายทุกรูปในโฟลเดอร์
```

ปรับค่าได้ที่หัวไฟล์ `run_model.py` เช่น โมเดล, แหล่งข้อมูล และความมั่นใจขั้นต่ำ ส่วนโค้ดที่อยากให้ทำงานเมื่อตรวจพบผล ใส่ในฟังก์ชัน `on_result`
ดูตัวเลือกทั้งหมดด้วย `--help`

## การเลือกโมเดล

| ชนิด | การใช้งาน |
| --- | --- |
| ในโปรเจกต์ | ใช้ไฟล์ใน `my-model/` |
| ลิงก์ | วางลิงก์ที่ได้จากปุ่ม **Upload my model** แล้วโมเดลจะเปลี่ยนทันที และแอปจะจำลิงก์ล่าสุดไว้ |
| ไฟล์ | เลือก `model.json`, `metadata.json` และ `weights.bin` พร้อมกัน |

ถ้าต้องการให้มีโมเดลในรายการเพิ่ม ให้วางโฟลเดอร์โมเดลไว้ข้าง `my-model/` แล้วเพิ่มรายการใน `BUILT_IN_MODELS` ที่ต้นไฟล์ `app.js`

## ข้อมูลเข้า

- **กล้อง**: เลือกกล้อง กลับภาพซ้าย-ขวา และเปิดปิดโครงร่างได้
- **อัปโหลดรูปภาพ**: ทดลองกับรูปใน `../Data-Test/` ได้

## ข้อมูลที่ใช้เทรน

โมเดลตั้งต้นเทรนจากภาพคนจำลองที่เรนเดอร์ด้วยโปรแกรม จึงยังไม่แม่นกับคนจริงหน้ากล้องเท่าโมเดลที่เทรนจากภาพจริง
ถ้าต้องการใช้งานจริง ให้เปิด `../project.tm` ใน Teachable Machine แล้วเก็บตัวอย่างเพิ่มด้วยปุ่ม **Webcam** ก่อนเทรนใหม่
